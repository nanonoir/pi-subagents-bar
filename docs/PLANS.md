# Execution plans

Use an execution plan for work complex enough to need durable coordination or recovery. Place in `exec-plans/active/` while in progress. Record the objective, context, scope, execution steps, progress, decisions and validation. Update the plan as work proceeds, including deviations and unresolved issues.

When finished, append the final implementation outcome and validation results, then move the plan to `exec-plans/completed/`. Keep concrete unresolved technical debt in `exec-plans/tech-debt-tracker.md`; a plan is not a general backlog.
